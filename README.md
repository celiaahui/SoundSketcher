
# SoundSketcher 🎵

SoundSketcher is a music editor I developed in Java for my CS1420 course at the University of Utah. The application allows users to create and edit music by adding notes and changing volume levels on different tracks. It also uses MIDI to play the music.

This project helped me practice object-oriented programming while learning how to build an interactive application using Java Swing.

## Features

- Create music using up to 10 different tracks.
- Add musical notes and adjust their pitch and duration.
- Change the volume of individual tracks.
- Choose different instruments for each track.
- Play music using MIDI.
- Adjust the tempo and song length.
- Save and load songs from files.
- Edit tracks using an interactive graphical interface.

## Technologies Used

- **Java** – Main programming language
- **Java Swing** – Graphical user interface
- **Java MIDI API** – Music playback
- **Eclipse IDE** – Development environment

## How to Run

1. Download or clone this repository.
2. Open Eclipse IDE.
3. Import the project as a Java project.
4. Make sure Java 17 or a compatible version is installed.
5. Open `src/assign12/SoundSketcher.java`.
6. Right-click the file and select **Run As → Java Application**.

## What I Learned

Working on SoundSketcher helped me understand how different Java classes work together in a larger project. I practiced inheritance, polymorphism, event handling, file operations, and creating graphical interfaces.

One of the most interesting parts was connecting the music editor to MIDI playback and seeing how the different components worked together to create music.

## Project Structure

The project includes classes for managing musical events, organizing songs, handling MIDI playback, reading and writing files, and building the user interface.

Some starter code was provided by the CS1420 course staff, and I completed the assigned implementations and features as part of the course.
